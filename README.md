# Chat Application

## About
A full-stack chat application that allows two users to send and receive messages in a shared conversation.

## Features
- Send and receive messages between two users.
- Automatically update messages between browser windows.
- Store messages permanently in an SQLite database.
- Delete individual messages.
- Clear a conversation.
- Validate user input.
- Handle backend errors.

## Technologies Used
- React
- JavaScript
- Node.js
- Express.js
- SQLite
- HTML
- CSS

## Project Structure
- `frontend/` – React user interface.
- `backend/` – Express server and SQLite database.
- `README.md` – Project documentation.
